# 🚀 CRIAR NO GITHUB AGORA - 2 MINUTOS

## Seu projeto enjoygo já está 100% pronto!

### PASSO 1: Criar repositório no GitHub (30 segundos)
1. Abra: **https://github.com/new**
2. Nome: `enjoygo`
3. Deixe **Public**
4. **NÃO** marque "Add README"
5. Clique em **Create repository**

### PASSO 2: Enviar código (copie e cole no terminal)

Depois de criar, o GitHub vai mostrar uma página com comandos. Use este:

```bash
# No seu PC, dentro da pasta enjoygo:
git remote add origin https://github.com/SEU_USUARIO/enjoygo.git
git push -u origin main
```

**SEU_USUARIO** = seu nome de usuário do GitHub

### PASSO 3: Ativar GitHub Pages (20 segundos)
1. No repositório, vá em **Settings** → **Pages** (no menu lateral)
2. Em **Build and deployment**, selecione: **GitHub Actions**
3. Pronto! O deploy começa automático

### PASSO 4: Jogar!
Em 1-2 minutos, seu jogo estará em:
**https://SEU_USUARIO.github.io/enjoygo/**

Esse link funciona pra sempre, sem erro de ngrok, sem Expo Go! Abre no celular e joga.

## 💻 Se quiser rodar local (sem GitHub):

```bash

npm run web
# Abre em http://localhost:19006

# Ou com Expo Go sem tunnel (mesmo Wi-Fi):
npx expo start --lan
```
